**Create React new proj :**

npx create-react-app react-http		(react-http : project name)





navigate to proj :

cd .\\react-http\\





to run proj :

npm start





Go Up 1 Level (Parent Directory) :

cd ..

Go back 2 levels :

cd ../..

Go back 3 levels :

cd ../../..

Go to your User Home folder :

cd or cd \~





To stop the running proj :

ctl+c







Shortcut for Function :

rfc





Shortcut for Class :

rce





Shortcut for React Arrow Function Export Component :

rafce
